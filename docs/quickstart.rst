Absolute Quickstart
===================

Welcome to the ultra-lightweight frontend framework - `CuteFront <https://github.com/elsampsa/cutefront>`_!

1. Create a new, empty directory for your project and start Claude Code in it:

.. code-block:: bash

    mkdir my_cute_app
    cd my_cute_app
    claude

2. Tell Claude:

.. code-block:: text

    Please read
    https://raw.githubusercontent.com/elsampsa/cutefront/main/vscode-configs/cute-project-init.md
    and follow its instructions

3. Claude sets up the project and walks you through it.  Start developing!
